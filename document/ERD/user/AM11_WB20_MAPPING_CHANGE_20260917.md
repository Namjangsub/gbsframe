# AM11-WB20 결재선 매핑 키 보관 변경

## 변경 사유

AM 전자결재 승인 시 WB20 결재행을 승인자·문서번호·순번으로 재검색하면 결재선 변경 또는 데이터 매핑 차이로 갱신 대상이 0건이 될 수 있다. WB20 최초 생성 시 확정된 원본 식별자를 AM 결재선에 보관해 승인 시 동일 행을 1:1로 갱신한다.

## 영향 범위

- `TB_AM11D01`에 WB20 원본 식별 컬럼을 추가한다.
- AM11 결재선 생성/조회 API와 WB20 연계 승인 로직이 해당 값을 전달·사용한다.
- 기존 행은 NULL 허용으로 하위 호환하며, 신규 WB20 연계 문서부터 값을 저장한다.
- 결재 상태 전이, `TODODIV*` 코드, 기한 없음 정책은 변경하지 않는다.

## 버전 전략

- DB 배포: 컬럼 추가 후 애플리케이션 배포
- 애플리케이션은 매핑 값이 있는 신규 문서를 우선 사용하고, 기존 NULL 행은 기존 연계 검증 경로로 처리한다.
- API 필드는 선택적 응답/내부 전달 필드로 추가해 기존 요청 필드와 상태코드를 변경하지 않는다.
