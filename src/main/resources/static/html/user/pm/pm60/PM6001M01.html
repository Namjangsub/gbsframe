2. 간트 차트 마우스 조작 방법

  • 일정/담당자 드래그 이동: 출장 바를 잡고 좌/우/상/하로 드래그하면 파란 수직 점선 테두리가 최상단에 나타나며, 마우스를 놓으면 1일 단위로 자동 스냅 저장됩니다.
  • 출장 기간 변경 (Resize): 출장 바의 좌측/우측 끝 핸들을 드래그하면 시작일/종료일을 손쉽게 늘리거나 줄일 수 있습니다.
  • 외주 투입 바 복사 (Ctrl + Drag): 외주 바를 Ctrl 키를 누른 채 드래그하면 동일한 내용의 새 바가 복사 등록됩니다.
  • 더블클릭 상세조회: 하단 실적 바(어두운 바)를 더블클릭하면 출장복명서 / 출장신청서 / 작업일보 상세 팝업이 바로 열립니다.
  • 신규 일정 등록: 캘린더의 빈 날짜 영역을 마우스로 드래그하면 출장 예약 및 외주 투입 등록 팝업이 실행됩니다.

3. 간트 바 표시 규칙

모든 차트의 바는 [출장유형] 현장명(프로젝트명) 포맷(예: [설치 및 시운전] 서연이화 울산공장(현대차PJT))으로 일관되게 표시됩니다.
