연차지급 산정기준 안내 (고용노동부 근로기준법 제60조 회계연도 부여 지침)
  • 입사 첫해 (1년차): 1개월 개근 시 다음달 1일 1개씩 개별 생성 (최대 11개) , 입사 2년차 1월 1일: 노동부 회계연도 비례 부여 [ 15일 × (전년도 재직일수 / 365), 0.5일 단위 정밀산정 ]
  • 2년~3년차 1월 1일: 매년 1월 1일 기본 15일 일괄 부여 , 4년차 이상 1월 1일: 최초 1년 초과 매 2년마다 1일 가산 [ 15일 + Math.floor((근속년수 - 1) / 2), 한도 25일 ]
